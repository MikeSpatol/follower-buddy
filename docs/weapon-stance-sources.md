# Weapon stance sources

Written by `tools/cache-dumper` (`gradlew runStanceMerge`) on 2026-10-08. Do not edit by hand: rerun the tool.

The shipped stance library, `src/main/resources/com/follower/stances.json`, is built from three sources and nothing else:

1. Stances this plugin learned by watching players (the learned `stances.json` and the previous bundle). They win for idle, walk, run and the turns.
2. Weapon Animation Replacer by geheur, BSD-2-Clause (see THIRD-PARTY-NOTICES.md), commit `504f6bd6d208aeca18e6ebb0dfd05f45a50a2daf`: its observed pose tuples, then its animation sets, reaching every variant through RuneLite's ItemVariationMapping. Its stab, slash and crush swings win over learned attacks.
3. The game cache and RuneLite's gameval names: every id must exist and be on the player skeleton, the combat tab's table says which blow each style button deals, and Jagex's names mark the blocks, specials and spell casts.
